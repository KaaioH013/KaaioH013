### 01 · SalesOps Industrial Demo
**Aplicação web para demonstrar uma operação comercial B2B.**

Reúne dashboard, clientes e registro de atividades em uma aplicação com perfis de administrador, gerente e vendedor. Demonstra como organizar a informação comercial e controlar o acesso de cada perfil.

- **Competências:** desenvolvimento full stack, modelagem de dados e autorização no servidor.

### 02 · Gerador de relatórios comerciais
**De uma planilha de vendas a relatórios PDF e HTML.**

Consolida indicadores, comparações entre períodos e verificações de qualidade dos dados. O foco é apoiar a preparação de análises comerciais a partir de arquivos Excel.

- **Competências:** tratamento de dados, indicadores comerciais e geração de documentos.
- **Tecnologias:** Python · pandas · CustomTkinter · Jinja2 · WeasyPrint.
- **Para explorar:** arquivo Excel de exemplo e instruções de execução no repositório.

### 03 · TranscritorSAJ
**Transcrição de áudio voltada à rotina de certificação de mandados.**

Aplicação desktop para transformar áudios em texto que pode ser revisado e utilizado no fluxo de trabalho do SAJ. Explora transcrição via API e processamento local com Whisper.

- **Competências:** integração de IA, processamento de áudio e distribuição de software desktop.
- **Tecnologias:** Python · Groq API · Whisper · PyInstaller.
- **Para explorar:** instalação, configuração dos motores e instruções de uso no repositório.

[**Conhecer o projeto →**](https://github.com/KaaioH013/TranscritorSAJ)
